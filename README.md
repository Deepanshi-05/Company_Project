# 📚 Library Management System (Python)

A simple Library Management System built using Python.  
This project allows users to issue and return books, and admins to manage library records.

Developed as a company assignment to demonstrate basic CRUD operations and system flow.

---

## Features

### User
- Login
- View available books
- Issue book
- Return book
- View fine

### Admin
- Add books
- Update books
- View issued books
- Reports

---

## Tech Stack
- Python  
- Django / Flask  
- SQLite  

---

## How to Run

```bash
pip install -r requirements.txt
python manage.py runserver
